# Could Protons Program a Low-Loss Optical Weight on Silicon Nitride?

**Status: work in progress (v0.4).** A pre-experimental decomposition of an untested hypothesis, not a device proposal. It is presented as an experiment-prioritization case study; the method draws on existing practice and is not claimed as new. No device data; every number is a published literature value, not a result of this work.

`index.html` breaks the hypothesis into six links (low-loss index response, reversibility, doping density, retention, sealed source, background loss), gives the nearest published evidence for each with its limits, states three tensions, and proposes a cheap flat-substrate first test. A verification ledger ties every cited claim to a resolved reference, and tombstones record withdrawn or narrowed claims.
